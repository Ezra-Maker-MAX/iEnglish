# 美术与视频资源生成（Agnes AI）

> 本文记录本项目的图像 / 视频素材生成链路，以及选型过程中实测出的平台约束。
> 所有结论均为 2026-09 在本机实测，非文档抄录 —— 文档与实际行为有出入的地方已标注。

## 一、为什么在此处接入生成模型

9 岁孩子对「软件感」极度敏感。纯文字 + emoji 的界面对成人够用，对孩子偏冷。
因此在三个位置引入素材：

| 位置 | 素类型 | 文件 | 作用 |
| --- | --- | --- | --- |
| 角色卡 / 对话气泡 | 角色立绘 | `public/avatar-max.png` | 让 Max 成为「一个人」而不是一个头像字母 |
| 关卡清单 / 结算页 | 关卡图标 ×4 | `public/icon-*.png` | 替换 emoji，统一视觉语言 |
| 开场 / 通关 | 短视频 | `public/intro-airport.mp4` | 进入场景时的仪式感 |

**硬约束（用户指定）：只用免费的那款。** → 图像 `agnes-image-2.5-flash`，视频 `agnes-video-2.5-flash`。

## 二、图像生成

### 端点
```
POST https://apihub.agnes-ai.com/v1/images/generations
```

### 请求体（实测可用的最小集合）
```json
{
  "model": "agnes-image-2.5-flash",
  "prompt": "...",
  "size": "1K",
  "extra_body": { "ratio": "1:1", "response_format": "url" }
}
```

**踩坑**：
- `size` 取值 `1K` / `2K` / `3K` / `4K`。**不要传 `1024x1024`**。
- `ratio` 与 `response_format` 必须放在 `extra_body` 里，放顶层无效。
- **不要加 legacy 的 `tags` 字段**，会报参数错误。
- 返回 `data[0].url` 或 `data[0].b64_json`，两种都要处理。

### 免费额度
- 4000 张 / 天
- 1K 分辨率 RPM：公开 30 / 实际可执行 20

### 美术风格一致性
批量生成时**必须共用一段风格前缀**，否则每个图标风格各异、拼在一起像素材拼盘。
本项目用的前缀（见 `scripts/gen-assets.cjs` 的 `STYLE` 常量）：

```
flat vector illustration for a children's app, thick clean dark outlines,
soft pastel palette, simple rounded shapes, cute and friendly, centered composition,
plain solid light background, no text, no letters, no watermark
```

关键点：`no text, no letters` —— 否则模型喜欢往图标上写英文字母，对孩子是干扰。

## 三、视频生成

### 端点
```
POST https://apihub.agnes-ai.com/v1/videos                  # 创建
GET  https://apihub.agnes-ai.com/agnesapi?video_id=<ID>&model_name=agnes-video-2.5-flash  # 轮询
```

### 请求体（实测通过的组合）
```json
{
  "model": "agnes-video-2.5-flash",
  "prompt": "...",
  "seconds": "5",
  "mode": "text",
  "size": "720P",
  "aspect_ratio": "1:1"
}
```

**踩坑（都是实测撞出来的）**：
1. **`mode` 是必填**，缺了直接 `400 mode is required`。合法值只有三个：
   `"text"` / `"keyframe"` / `"reference"`。
   → 试过 `text2video` / `txt2video` / `text_to_video` 全部 `400 invalid mode`。
2. **`seconds` 必须是字符串**（`"5"` 而非 `5`），范围 `"4"`–`"12"`。
3. **`duration` 不是合法字段**，传了报 `duration is not an allowed request field`。
   用 `seconds`。
4. **Flash 版 `size` 只能传 `"720P"`**，其他值（含 `1080P` / `1K` / `2K`）返回 `400`。
   分辨率改由 `aspect_ratio` 控制：`16:9`→1280x704，`1:1`→720x720，`9:16`→720x1280。
5. **轮询必须带 `model_name`**。只带 `video_id` 仅对 `mode:"text"` 有效；
   `keyframe` / `reference` 模式不带会查不到。
6. **用 `video_id` 轮询，不是 `task_id`**。返回体里 `id` / `task_id` 标识异步任务，
   `video_id` 才是查询凭据。
7. 响应里 `internal_status` / `internal_progress` 是内部字段会一直显示 `pending` / `0`，
   **判断进度要用 `status` 和 `progress`**。

### 免费额度的现实约束 ★
- **RPM：公开 2 / 实际可执行 1** —— 一分钟只能真正跑起来一个视频任务。
- 500 秒 / 天。
- **队列经常满**：实测**连续 16 分钟、22 次尝试全部返回 `503 video_queue_full`**。
  两次独立的长跑尝试（含一次 40 次重试）均未能拿到任务。
  → 结论：**视频适合离线批量生成后随包发布，不适合在请求链路里实时生成**，
  且**需要挑低峰时段**（建议夜间）。

### 本项目的视频状态

## 四、重试策略（两种模型通用）

以下状态码必须重试，指数退避：`408 / 429 / 500 / 502 / 503 / 504 / 520 / 522 / 524`

补充：
- `503 video_queue_full` 也是可重试的（队列满），间隔建议 ≥ 60s。
- `500 Failed to reach upstream` 实测重试后可成功 —— 不要当致命错误。

## 五、运行方式

```bash
# 需要 API Key 写在 C:/Users/lenovo/AppData/Local/Temp/agnes_key.txt
unset http_proxy https_proxy ALL_PROXY    # 本机代理会拦外网请求

node scripts/gen-assets.cjs         # 角色立绘 + 4 个关卡图标（图像，秒级完成）
node scripts/gen-intro-video.cjs    # 机场开场短视频（长跑重试，建议低峰时段）
```

脚本设计原则：**已存在的文件跳过而非覆盖**。原因有二 ——
一是避免重复消耗免费额度，二是允许人工挑选后替换个别不满意的素材。
（本机有 safe-delete hook 会拦截删除操作，所以脚本内不做任何清理逻辑。）
